🔔 Alerts

Push notifications when something noteworthy happens. Configured here — no env vars, no config files. Either channel (Discord or ntfy) can be used; both are optional. Alerts are edge-triggered (one ping per state change) so they don't spam.

Discord webhook URL
ntfy.sh topic
Topic is required; server defaults to https://ntfy.sh. Self-hosted ntfy works too.
Minimum severity
Disk alert threshold (%)

Triggers: container unhealthy/exited non-zero/dead, systemd unit failed, GPU VRAM pressure (free < PRESSURE_FREE_MB), GPU OOM events, and disks crossing the threshold above.
