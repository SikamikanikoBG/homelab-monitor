Homelab Agents — layout options

Clickable mockup with example data. Walk the flows: ask in chat, approve the restart card, activate a template, set a box to Active, open an audit run. The same screens appear in all three options; only where they live changes.

Flow · US-6/7 chat → act
  1. Ask "Why is gpu-box slow?" → streamed answer with tool chips (get_gpu, get_containers).
  2. Ask "restart ollama there" → policy check: gpu-box Active, restart = Ask → confirm card.
  3. Approve → runs, chip shows result; Reject → model told "rejected by user".
  4. Error: box Passive → "Not allowed: gpu-box is Passive. Change in Agent policy." Empty: no model → setup card.
Flow · US-8/10 template → approval
  1. Automations → gallery → Docker cleanup → Activate.
  2. Pick hosts, schedule (Sun 03:00), mode (Act within policy), model, delivery.
  3. 03:00 run: prune dangling images (low, Allow) runs; remove unused volumes (med) → pending approval + ntfy.
  4. Morning: Approvals badge → approve → executes, audited against the night run.
Flow · US-4/5/11 policy & audit
  1. Agent policy: per host Off / Passive / Active; per action Deny / Ask / Allow; high risk locked to Ask unattended.
  2. Activity: every run, filter by host/outcome; click → step timeline with args, policy decision, approver, result.
  3. Export JSON/CSV. ENABLE_CONTROLS=0 → banner, all actions show Deny.
